# Icons

This app uses **Google Material Icons** via [`react-icons`](https://react-icons.github.io/react-icons/icons/md/).

All icons are defined in `components/icons/index.tsx`. Browse available icons at [Google Material Icons](https://fonts.google.com/icons) and use the matching `Md*` name from `react-icons/md`.
